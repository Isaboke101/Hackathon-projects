## Repository structure

Each project folder should contain the materials needed to understand and use that project:

```text
project-folder/
├── README.md          # Problem, solution, setup, and usage
├── src/               # Application source code (when applicable)
├── docs/              # Design notes, diagrams, or presentation material (when applicable)
└── ...                # Other project-specific assets
```

## How to explore

1. Choose a project from the table above.
2. Open its folder and start with its `README.md`.
3. Follow that project's setup and usage instructions.

Requirements vary by project; check the individual README for its dependencies, configuration, hardware, data, or API requirements.

## Adding a project

When adding a new hackathon project:

1. Create a clearly named folder at the repository root. A consistent format such as `YYYY-event-project-name` works well for larger collections.
2. Add a project-level `README.md` that explains the challenge, approach, features, technologies, setup, and any team or demo links.
3. Add the project to the table above.
